# Postpartum depression dataset

Source: Jasiya Fairiz Raisa and M. Shamim Kaiser, *Data for Postpartum Depression
Prediction in Bangladesh*, Mendeley Data, version 3, DOI `10.17632/4nznnrk8cg.3`.

Licence: CC BY 4.0. The files in this directory are unmodified source CSV files unless
an explicitly named processed artifact states otherwise.

This is structured screening and risk-factor data from 800 consenting postpartum
participants. It supports supervised screening-risk experiments; it is not conversational
Q&A and is not itself the retrieval knowledge base.
